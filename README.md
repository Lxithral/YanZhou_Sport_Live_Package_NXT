# 烟洲体育直播包装 NXT

面向校园体育赛事的本地导播台与 OBS 透明图层。沿用 `YanZhou__Live__pkg_NXT-main` 的 Node.js 本地服务、WebSocket 状态同步、导播台和输出页分离的做法。赛事、名单、成绩和图层设置保存在本机。

## Windows 便携包

1. 将 `YanZhou-Sport-Live-NXT-1.5.2-Windows-x64.zip` 完整解压到有写入权限的目录。
2. 双击 `start.cmd`，然后在浏览器打开 [导播台](http://127.0.0.1:3120/control.html)。直播期间请保留启动窗口。需要自动打开浏览器时运行 `start.cmd --open`。
3. 在 OBS 添加「浏览器」来源。保持「本地文件」关闭，URL 填 [输出地址](http://127.0.0.1:3120/overlay.html)，宽 **1920**、高 **1080**。将浏览器源放在摄像机来源上方。
4. 如画面动效不够顺滑，可跟随 OBS 的输出帧率把浏览器源设为 **60 FPS**。保持「不可见时关闭来源」与「场景激活时刷新浏览器」关闭。[OBS 浏览器来源文档](https://obsproject.com/kb/browser-source)

导播台的棋盘格和深灰只是监看底图。将透明输出地址添加为 OBS「浏览器」来源后，空白区域会透出下方的视频。普通浏览器窗口由桌面提供底色，直播叠加请直接使用浏览器来源。

便携包内置 Windows x64 Node.js 与 WebSocket 依赖，解压后可离线运行。导播台和 OBS 在同一台电脑上使用。若 3120 端口已被占用，可在 PowerShell 中运行 `$env:YANZHOU_PORT = '3121'` 和 `.\start.cmd`，再用导播台复制新地址。

## 一屏导播

宽屏左侧是「画面输出」，中间是 16:9 监看，右侧是「选手名单」。窄屏用顶部的「选手名单 / 监看与输出」切换工作区。导播台支持跟随系统、浅色和深色主题。

1. 在右侧「选择上屏赛事」选中目标赛事，再点「切换赛事」。切换会立即更新监看和 OBS。每场赛事保留自己的名单、成绩、图层设置和上屏状态，切回时恢复。新安装默认有高一、高二男女子 800 米四场决赛，旧数据中的其他赛事仍可在列表中选择。
2. 点「添加选手」录入姓名、班级、道次和成绩。已有选手可以直接在表格内修改，按回车或离开输入框保存。径赛成绩可填 `2:05.32`、`125.32` 或 `2分05秒32`。田赛可用 `5.10|X|5.32` 记录试次，`X` 表示犯规，`-` 表示放弃。特殊成绩可填 `DNS`、`DNF`、`DQ` 或 `NM`。
3. 在「起跑介绍」选择选手，再点「上屏」。介绍上屏时会替换赛事条和冠军卡。补录选手和修改道次时会保留当前介绍的人选。删掉正在介绍的选手会收起该图层。
4. 点选手行的「播冠军」把该选手推送到画面，点「下屏」收起。比赛排名和班级计分独立保存。选手尚无成绩时卡片显示 `—`。删除上屏冠军或将其成绩改为无效状态时，冠军卡会收起。

## 调整布局与 OBS 输出

- 点击图层标题可编辑位置、大小、透明度和动画。可输入坐标、对齐四角安全区，或在打开「拖动图层」后直接拖动监看中的图层。编辑自动保存。布局面板会显示保存状态，失败时可重试。「恢复默认」重置该图层的布局和动画。
- 监看顶栏可切换棋盘格和深灰底，也能打开安全区。底部的「复制」和「打开」使用当前服务端口的透明 OBS 输出地址。
- 默认挂角使用白色 `YZBTVS SPORT` 字标和金色「洲」标志。可在 Logo 布局中修改右下角文字。冠军卡或其他图层靠近金标时，金标会自动让出空间。输出地址加 `?branding=legacy` 可改用旧版校徽和绛红字标。
- 监看断线时会标记并保留最后一帧图层。导播台收到重连快照后恢复上屏操作。成绩草稿和保存失败的布局可核对后重试。

数据写入 `data/settings.json`。可以在退出服务后备份整个 `data` 目录，服务重启会恢复上次保存的赛事和画面。

## 从源码启动和打包

需要 Node.js 22 以上版本。

```powershell
npm.cmd ci
npm.cmd start
npm.cmd test
node tools/check-ui.mjs
```

`npm.cmd start` 后手动打开导播台。从源码运行时可以用 `node tools/check-ui.mjs` 自查界面：它用临时数据目录起一个实例，无头浏览器跑一遍行内录入、切换赛事、上屏与下屏、布局调整和多档窗口尺寸，把截图与结果写到 `dist/ui-review`（需要本机有 Chrome / Chromium / Edge，可用 `CHROME_PATH` 指定；便携包里没有这个脚本）。运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\package-windows.ps1` 生成 `dist` 下的 Windows 便携 ZIP 及 SHA-256 校验文件。构建使用 [Node.js v24.22.3 Windows 发行包](https://nodejs.org/en/blog/release/v24.22.3/)，运行时许可证随包分发。
