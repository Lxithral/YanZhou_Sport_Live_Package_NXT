# 烟洲体育直播包装 NXT

面向校园运动会和球赛的本地导播台与 OBS 透明图层。沿用 `YanZhou__Live__pkg_NXT-main` 的 Node.js 本地服务、WebSocket 状态同步、导播台和输出页分离的做法。正式赛事、名单、成绩、比分和图层设置保存在本机。

## Windows 便携包

1. 将 `YanZhou-Sport-Live-NXT-1.5.2-Windows-x64.zip` 完整解压到有写入权限的目录。
2. 双击 `start.cmd`，然后在浏览器打开 [导播台](http://127.0.0.1:3120/control.html)。直播期间请保留启动窗口。需要自动打开浏览器时运行 `start.cmd --open`。
3. 在 OBS 添加「浏览器」来源。保持「本地文件」关闭，URL 填 [输出地址](http://127.0.0.1:3120/overlay.html)，宽 **1920**、高 **1080**。将浏览器源放在摄像机来源上方。
4. 如画面动效不够顺滑，可跟随 OBS 的输出帧率把浏览器源设为 **60 FPS**。保持「不可见时关闭来源」与「场景激活时刷新浏览器」关闭。[OBS 浏览器来源文档](https://obsproject.com/kb/browser-source)

导播台的棋盘格、深灰和跑道只是监看底图。将透明输出地址添加为 OBS「浏览器」来源后，空白区域会透出下方的视频。普通浏览器窗口由桌面提供底色，直播叠加请直接使用浏览器来源。

便携包内置 Windows x64 Node.js 与 WebSocket 依赖，解压后可离线运行。导播台和 OBS 在同一台电脑上使用。若 3120 端口已被占用，可在 PowerShell 中运行 `$env:YANZHOU_PORT = '3121'` 和 `.\start.cmd`，再用导播台复制新地址。

## 一屏导播

界面按直播现场的手感分成三栏：左边「画面输出」管图层开关和图层位置，中间是节目监看与局部放大，右边「赛事工作台」管赛事、名单、成绩和名次。顶部一直显示当前赛事与是否有画面在播，右上角是输出地址、复制地址和直播信息。

高频操作全部留在页面上，不弹窗：名次表上方就是「快速录入」，填号码（或姓名）和成绩回车即记录，焦点自动回到号码框等下一位；表内每行的「录入/入榜」打开行内编辑器，跳高直接给免跳、失败、过杆和撤销按钮；「备赛名单」里的「添加选手」是表格上方的内联表单。只有新建赛事、直播信息这类低频设置仍然使用弹窗。

顶部可在「男子」「女子」之间切换，再从当前组别选择赛事。切换组别时优先进入同项目、同轮次的赛事，并把画面上除左上角 Logo 以外的图层收掉，避免上一场的成绩停在新一场的直播画面上。新增赛事时可以指定比赛组别和轮次。工作台用「赛程 / 名次与成绩 / 备赛名单」三个页签切换，窄屏时顶部的「赛事工作台 / 监看与输出」用来在两次屏之间来回切。

每场赛事保存自己的名单、成绩、排名、图层位置、显隐、翻页和挂角。切换赛事会自动把对应配置送到节目监看和同一个 OBS 输出地址，切回后恢复该场状态。升级旧版时，已有赛事和成绩会保留，原先的共享布局会用作各场初始布局，已上屏的名单和成绩归入原先的当前赛事。

在左侧「画面输出」点选图层，即可调整显隐、位置、大小、透明度和动画。默认位置与四角按钮对齐到监看的安全区。选四角时，过大的图层会缩到能放进安全区的尺寸。监看底图与安全区可在监看顶栏控制。左上挂角使用原项目校徽和绛红色 YZBTVS 字标，右侧配较小的 SPORT。可在「直播信息」填写挂角副标题和榜单页脚。

## 第五届「烟伙杯」校运会

赛事列表默认加载本届校运会的 49 个条目。方案中 11 月 27 日、28 日有 42 场正式排期。高一、高二男子 1000 米和两个年级的男女子 1500 米列为时间待定。教职工团体赛放在 27 日下午，支持先导入队伍。以正式秩序册为准，可用「编辑赛事」调整开赛时间。赛程会提前 25 分钟显示检录时间。

1. 在「赛程」按时段、年级筛选，点「名单」可先备赛，点「切换」才会切换实际输出。名单在页内「添加选手」逐行填写，单位填写班级。
2. 径赛名单可填「分组」「道次」。赛后按裁判报出的时间在选手行「编辑」中录入成绩。100 米、200 米预赛确认名次后可用「晋级到决赛」生成对应的决赛名单，再按秩序册分配道次。
3. 跳远、铅球在选手行点「记试次」，铅球标注男子 5 kg、女子 4 kg。跳高女子 95 cm、男子 130 cm 起跳，分别到 115 cm、150 cm 后每档增加 3 cm。可逐人记过杆、失败、免跳和撤销上次。
4. 50 米迎面接力按班级或队伍录入，每队 10 人，男、女各 5 人。填人数后工作台会标记核验状态，可按裁判决定处理资格。4×100 米接力同样按队伍记录成绩。
5. 决赛核对名次和班级后点「确认计分」。班级积分按年级汇总，个人项前八名为 9、7、6、5、4、3、2、1 分，接力双倍。已确认决赛中超过原校纪录的最高有效成绩获得双倍计分。仍同分且破纪录数和各名次次数相同的班级标记「待抽签」。班级积分只在工作台里查看。

## 赛前导入与赛后排名

1. 在「备赛名单」页签的「名单赛事」选择目标组，再用「添加选手」逐行填写。可用「创建待播赛事」先建下一组，当前画面会继续播出。
2. 切换到目标赛事。赛后把选手拖到表内的蓝色落点即可追加名次，拖到已排名的两行之间可换位。也可用行末的「入榜」「撤回」，聚焦已排名选手的拖动手柄后按 ↑ / ↓ 可微调名次。
3. 点左侧「画面输出」里冠军榜卡片上的「上屏」。之后调整名次会即时更新 OBS。只确认名次时，成绩列显示 `—`。填入时间或距离后会随名次显示。
4. 按成绩排序可继续使用。点击「恢复按成绩」会清除手动名次，并根据已录入的径赛或田赛成绩重新排名。

## 1000 米成绩录入

1. 选择「1000 米」，用「编辑赛事」设置组别、赛场和跑道每圈距离。不同组次可各建一项。
2. 用「添加选手」录入名单，也能直接粘贴号码和成绩。在「画面输出」的「起跑介绍」卡片中先选择选手，再打开显示；隐藏时也能下拉直选或按「上一位 / 下一位」备播，上屏后保留所选选手。卡片同时显示当前姓名、号码和下一位。
3. 赛后按裁判报出的时间，在选手行点「编辑」填写成绩并保存。状态可录入 DNS、DNF、DQ。
4. 在名次表核对名次。可拖动调整顺序，或点「恢复按成绩」按已录入的时间自动排序；同成绩并列。确认第一名后，点冠军榜卡片上的「上屏」播出右下角竖卡；只有 DNS / DNF / DQ 等无名次结果时不能上屏冠军。左侧冠军榜卡片可核对姓名、成绩并调整位置。

## 其他预设与图层

- **径赛**包含男女子 1500 米等赛事预设。可用 50、100、200、400、800、1000 米和接力预设新建赛事，也可自定义距离、每圈长度和棒数。
- **田赛**包含男女子铅球、跳远、跳高和自定义项目。逐次录入距离、犯规或放弃，成绩榜按最佳有效成绩排序，同成绩并列。
- **球赛**保留足球与自定义球赛，支持加减分和切节。启动新版时会从旧设置里移除篮球项目。
- **通用图层**包含 Logo 挂角、赛事条、起跑介绍和冠军。点选图层后可调整显隐、位置和外观，也可在监看里拖动上屏图层。赛事条是一条横向项目牌：左侧强调色竖条、项目名、组别与轮次副行。起跑介绍按参考图使用下方长横条与右端较高的斜切姓名块，横条显示号码、道次和班级；与独立赛事条互斥显示，避免撞层。冠军卡片固定为右下竖版，姓名在上、成绩在下。监看背景与安全区仅用于导播台。升级仅更新未调整过的旧默认介绍和冠军位置，保留自定义位置与显隐设置。

## 成绩格式与数据

径赛成绩可填 `03:21.52` 或秒数 `201.52`。田赛直接填成绩 `5.32`；要保留每次试投，在选手的「试次」里写 `5.10|X|5.32`，`X` 表示犯规，`-` 表示放弃。号码可留空，填写时同一场须唯一。状态可填 `ok`、`pending`、`DNS`、`DNF`、`DQ`、`NM`，留空时按成绩自动判断。

数据写入 `data/settings.json`。可在退出后备份整个 `data` 目录。服务重开后恢复上次状态。

## 从源码启动和打包

需要 Node.js 22 以上版本。

```powershell
npm.cmd ci
npm.cmd start
npm.cmd test
node tools/check-ui.mjs
```

`npm.cmd start` 后手动打开导播台。从源码运行时可以用 `node tools/check-ui.mjs` 自查界面：它用临时数据目录起一个实例，无头浏览器跑一遍快速录入、行内改成绩、切换组别收画面、图层开关和 1920 / 1366 / 1100 / 390 四档布局，把截图与结果写到 `dist/ui-review`（需要本机有 Chrome / Chromium / Edge，可用 `CHROME_PATH` 指定；便携包里没有这个脚本）。运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\package-windows.ps1` 生成 `dist` 下的 Windows 便携 ZIP 及 SHA-256 校验文件。构建使用 [Node.js v24.22.3 Windows 发行包](https://nodejs.org/en/blog/release/v24.22.3/)，运行时许可证随包分发。

导播台跑道背景由 ImageGen 生成，用于检查不同图层的遮挡和对比度。
